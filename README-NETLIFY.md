# Нино — полный проект для Netlify

Снимок исходного сайта: commit b1072c20e3dac07abf987cc70d8b1a8a4d08262e.
Дизайн, тексты, меню, цены, вес, изображения, корзина и клиентские обработчики сохранены без изменений.

## Публикация

1. Распакуйте архив. Создайте Git-репозиторий из содержимого папки `nino-netlify-latest` и загрузите его на GitHub/GitLab/Bitbucket.
2. В Netlify создайте проект из этого репозитория. Корневая папка — папка с `netlify.toml`.
3. Build command: `node scripts/build-netlify.mjs` (также `pnpm build:netlify`). Publish directory: `netlify-dist`. Functions directory: `netlify/functions`. Файл netlify.toml уже содержит эти настройки.
4. Node.js 22. Зависимости перечислены в package.json, точные версии зафиксированы в pnpm-lock.yaml; пакетный менеджер — pnpm 11.25.0. Для локальной установки используйте `corepack enable`, затем `corepack prepare pnpm@11.25.0 --activate` и `pnpm install --frozen-lockfile`.
5. Запустите Deploy. Используйте HTTPS-адрес Netlify или свой домен.

Простой перенос папки в Netlify Drop публикует только статические файлы и не разворачивает серверные функции. Для полного проекта используйте импорт репозитория и сборку. Для самостоятельной статической демонстрации можно собрать `netlify-dist`, но личный кабинет требует функций.

## Технология и состав

Реальный интерфейс сайта — `site/index.html`, `public/style.css`, `public/app.js`, `public/order-core.js`, `public/account.js`, `public/header.js` и `public/images`. Файлы копируются при сборке байт в байт, без перерисовки или смены технологии.

Исходная оболочка Vinext/React/Cloudflare сохранена: `app`, `build`, `vite.config.ts`, исходные scripts, конфигурации и зависимости. Обычная `pnpm build` относится к первоначальному Cloudflare-окружению. Для Netlify используйте отдельную команду выше: Cloudflare Worker нельзя разместить на Netlify как есть. Адаптер `netlify/functions/customer.mjs` вызывает тот же `server/customer.mjs`, без копирования бизнес-логики.

`node_modules`, .git, временные сборки, локальные базы и секреты в архив не входят. Зависимости устанавливаются из package.json и lock-файла. Пользовательские данные из рабочей базы в архив не экспортировались.

## Личный кабинет и SMS — нужны внешние настройки

Реальная отправка SMS не была подключена в исходном сайте. Без настроек сайт честно показывает недоступность входа; корзина работает без авторизации.

Для работы кабинета задайте в Netlify Environment variables (с доступом для Functions, не в браузере):

- CLOUDFLARE_ACCOUNT_ID — ваш аккаунт Cloudflare.
- CLOUDFLARE_D1_DATABASE_ID — ваша D1-база.
- CLOUDFLARE_D1_API_TOKEN — серверный токен с D1 Read/Write, ограниченный нужным аккаунтом.
- SMSRU_API_ID — ключ SMS.ru; SMSRU_SENDER — необязательный отправитель.
- OTP_HMAC_SECRET — случайный секрет длиной не менее 32 символов (например `openssl rand -hex 32`).
- TURNSTILE_SECRET_KEY и TURNSTILE_SITE_KEY — пара ключей Turnstile. Добавьте домен Netlify и свой домен в разрешённые hostname Turnstile.

Инициализируйте пустую D1-базу SQL-файлом `drizzle/0000_gorgeous_lord_hawal.sql`. Не запускайте миграцию повторно на уже подготовленной базе. Для переноса существующих аккаунтов потребуется отдельный безопасный экспорт/импорт вашей базы; архива исходников для этого недостаточно. Секреты не отправляйте в Git.

HTTP-адаптер D1 использует официальный серверный API Cloudflare, параметризованные запросы и пакетные операции. Подключение реальных внешних сервисов в этом архиве не проверялось.

## Существующие ограничения сохранены

- Серверной отправки/сохранения реальных заказов и эквайринга в проекте нет. Выбор карты, наличных и QR сохранён, но не означает подключённую онлайн-оплату.
- Бронирование использует существующий интерфейс; внешняя система бронирования не подключена.
- Корзина и черновики сохраняются в localStorage браузера. При переходе на новый домен они автоматически не переносятся между доменами.
- Автоматической надёжной проверки географической зоны доставки нет.
- Изображения и шрифты: все локальные изображения включены; шрифты Google Fonts продолжают загружаться внешним запросом как в исходном сайте.
